# AI Arena

One question. Multiple AI minds.

I got tired of opening three tabs just to see if ChatGPT, Claude, and Gemini agreed on something. So I built a place where they answer the same question at once, and you just... see what happens.

🔗 Live: [ai-arena-red.vercel.app](https://ai-arena-red.vercel.app)

## Right now

You can use your own API keys (ChatGPT + Gemini for now) and start comparing straight away. No signup. Your keys stay in your browser — I never see them, my server never sees them.

That's it for now. It's small on purpose.

## Roadmap

Phase 1 — foundation (current)
BYOK, no accounts, free forever. Get the core comparison experience solid before anything else.

Phase 2 — accounts + hosted tiers
For people who don't want to manage their own API keys. Multiple pricing tiers, starting cheap and scaling up to full flagship model access as the project grows.

Phase 3 — going deeper
Saved comparisons, model performance tracking, a way to discover smaller/less-known AI models beyond the big three.

Phase 4 — the fun stuff
Referrals, rewards for people who've been here a while, and features I'm still figuring out.

Nothing here is fixed in stone — this list will change as I learn what people actually want.

## Setup

1. Get a key from OpenAI or Google AI Studio
2. Paste it in
3. Ask something, see who answers better
